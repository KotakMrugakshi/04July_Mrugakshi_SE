CSS Box Model & Positioning

Margin: Space outside an element.

Padding: Space between content and border.

Border: The outline around an element.

Display: Controls how elements are laid out.

Relative: Positions an element relative to its normal position.

Absolute: Positions an element relative to its nearest positioned ancestor.

Fixed: Keeps an element in a fixed place on the screen while scrolling.
